# Sayari feature map: what each feature does → which customer story proves it

Built 2026-11-11 for the "variety" agenda (item 3): release notes and product pages as context and image sources, cross-referenced with the 20 case studies in `case-studies/`. Each row is a feature → story pair a post can use.

**Sources read**
- API change log: https://documentation.sayari.com/change-log/overview/api (2023 to Mar 2026)
- Risk factor change log: https://documentation.sayari.com/change-log/overview/risk-factors (Aug + Oct 2026 batches)
- Product pages: sayari.com/platform/ (+ /graph, /signal, /pilot, /guide, /agent-builder, /agent-composer)
- News releases: BIS50 launch, Sayari Map launch, 50 US states, Snowflake rebuild (2 Sep 2026), Mirato acquisition
- Sayari Learn (Notion): https://sayari.notion.site/learn (tutorials with real Graph screenshots)

**Product line in one breath (2026):** Superconductor = the AI platform underneath. Graph = search, ownership and networks (Supply Chain Mapping, formerly "Map", is now a Graph add-on). Signal = screening data for risk that isn't on any list (7 modules). Guide = third-party-risk workflows and case management. Pilot = AI that runs screening, document review and alert triage continuously. Agent Builder / Agent Composer = no-code agents with confidence gates and audit logs (beta / early access).

## Gotchas
- Most sayari.com news releases show 2026-04-07: that's a site migration date, not the real date (e.g. the Map launch and the 50-state release are years older). Check the date in the article body before citing.
- "Pilot" in case studies usually means a trial, not the Pilot product.
- docs.sayari.com redirects to documentation.sayari.com. The Learn site is Notion: page text loads after ~4 s and lives in `.notion-page-content`, not `main`.
