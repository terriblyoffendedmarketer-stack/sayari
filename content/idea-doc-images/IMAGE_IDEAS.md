# Idea-doc images: what each one is and how Sayari can use it

Source: the "image / reference dumps" section of the idea bank Google Doc (extracted 2026-11-09 with `scripts/extract_doc_images.py`).
Files are in `images/`, numbered in the order they appear in the doc.

**Current rule from Sayari:** no memes for now. Storytelling through images and carousels.
So the memes are kept for the **feeling** they capture. Every "Sayari version" below is a non-meme format (a realistic fake artifact, a typographic card, a chart, or a carousel) in Sayari brand style (navy #1D2440 / beige #FAF8F4 / one gold accent, Merriweather + Inter + JetBrains Mono, 1080x1350).

Legend: **F** = format reference (borrow the layout) · **P** = compliance pulse (borrow the insight, change the format) · **B** = brief/brand material.
