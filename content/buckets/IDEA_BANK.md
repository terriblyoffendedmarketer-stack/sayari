# Idea bank (all ideas, one row each)

Every **starting point** for a post, one row each. A post can start from any of four, and all are equally valid:
- `idea`: a concrete post concept ("questionnaire vs record")
- `insight`: an industry truth or pattern worth a post ("questionnaires get answered less than half the time")
- `angle`: a direction or series to explore ("tips to be a better analyst")
- `hook`: just a strong line; the post gets built around it
IDs: `I##` for ideas, insights and angles, `H##` for hooks. Add new rows with the next ID; the hub reads this table.
